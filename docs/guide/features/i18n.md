# 国际化 i18n

项目使用 vue-i18n@11.4.4 实现多语言支持，目前包含中文简体和 English 两套语言包。

## 快速切换

在 Header 组件中点击语言图标即可切换，或通过代码调用：

```ts
import { useLocale } from '@/composables/web/useLocale'

const { setLocale } = useLocale()

// 切换为英文
setLocale('en-US')

// 切换回中文
setLocale('zh-CN')
```

## 语言包结构

```
src/locales/
├── index.ts          # i18n 配置入口
└── lang/
    ├── zh-CN.ts      # 中文简体（350+ 键值）
    └── en-US.ts      # English
```

## 添加新翻译

### 1. 在中文语言包中添加键值

```ts
// src/locales/lang/zh-CN.ts
export default {
  common: {
    confirm: '确认',
    cancel: '取消',
    // 新增：
    save: '保存',
  },
  // ...
}
```

### 2. 在英文语言包中同步

```ts
// src/locales/lang/en-US.ts
export default {
  common: {
    confirm: 'Confirm',
    cancel: 'Cancel',
    // 新增：
    save: 'Save',
  },
  // ...
}
```

### 3. 在组件中使用

```vue
<script setup>
import { useI18n } from 'vue-i18n'

const { t } = useI18n({ useScope: 'global' })
</script>

<template>
  <button>{{ t('common.save') }}</button>
</template>
```

## 已支持的模块

| 模块 | 键值数量 | 说明 |
|------|----------|------|
| common | ~30 | 通用文案（确认、取消、保存等） |
| login | ~25 | 登录页相关 |
| menu | ~40 | 菜单名称 |
| user | ~35 | 用户管理 |
| role | ~20 | 角色管理 |
| dict | ~15 | 字典管理 |
| log | ~30 | 操作日志 |
| online | ~25 | 在线用户 |
| notice | ~30 | 消息通知 |
| settings | ~20 | 系统设置 |
| header | ~20 | 顶栏组件 |
| pagination | ~10 | 分页组件 |
| table | ~15 | 表格组件 |
| validation | ~20 | 校验提示 |
| error | ~6 | 错误页面 |

## 语言持久化

选择的语言会自动保存到 localStorage，下次访问时自动恢复。
