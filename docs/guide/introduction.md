# 项目介绍

Antdv Next Vue Admin 是一个**现代化企业级后台管理系统模板**，基于 Vue 3 + TypeScript + Antdv Next + Tailwind CSS 构建。

## 为什么选择本项目？

| 特性 | 说明 |
|------|------|
| 🚀 **最新技术栈** | Vue 3.5 + TypeScript 5.9 + Vite 7 + Antdv Next |
| 🎨 **Tailwind CSS v4** | 原子化 CSS，配合 `cn()` 工具函数，告别预处理器 |
| 🔌 **Alova HTTP** | 请求共享、响应缓存、Mock 数据无缝集成 |
| 🧩 **微前端就绪** | 内置 MicroAppContainer 组件，支持子应用管理 |
| 📱 **响应式布局** | 纯 Flex 布局，支持多种布局模式切换 |
| 🌍 **国际化** | vue-i18n 双语支持，350+ 翻译键值 |
| 📊 **数据操作** | Excel 导出、专业打印、批量操作 |
| 🔐 **权限完善** | 路由级 + 按钮级权限控制 |

## 适用场景

- 企业中后台管理系统
- SaaS 平台管理端
- 内部工具平台
- 数据可视化大屏
- 微前端主应用基座

## 技术选型理由

### 为什么用 Antdv Next？

Antdv Next 是 Ant Design Vue 的下一代版本，提供了：

- 更好的 TypeScript 支持
- 更小的包体积
- 更灵活的主题定制
- 与 Tailwind CSS 的完美结合

### 为什么用 Tailwind CSS v4？

- **原子化 CSS** — 无需编写自定义样式文件
- **JIT 模式** — 按需生成，极致精简
- **设计系统** — 通过 `cn()` 函数安全合并类名
- **暗色模式** — 原生支持，一行代码切换

### 为什么用 Alova？

相比 Axios，Alova 提供了：

- **请求共享** — 相同请求自动去重
- **响应缓存** — GET 请求自动缓存
- **Mock 集成** — `@alova/mock` 开发体验丝滑
- **自动重试** — 失败请求智能重试
