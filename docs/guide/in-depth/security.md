# 安全中心

安全中心是模板内建的安全运营入口，包含五个页面：

| 页面 | 路径 | 作用 |
| --- | --- | --- |
| 安全总览 | `/security/dashboard` | 评分维度（含 AI 安全）、威胁分布、告警与事件时间线 |
| 审计日志 | `/security/audit` | 全链路五元组审计，只读 |
| 脱敏策略 | `/security/mask-policy` | 配置字段脱敏规则并演练判定结果 |
| AI 安全策略 | `/security/ai-policy` | 提示词注入、输入脱敏、输出审核、留痕与限流阈值 |
| AI 调用审计 | `/security/ai-calls` | 每次 AI 对话的脱敏摘要、风险等级与处置结果 |

完整设计与合规对照见仓库根目录 `SECURITY.md`。

## 审计五元组

每次经过 `defineMockRoute` 的请求都会写入一条记录：`actor`（账号）、`action`（方法与路径）、`target`（请求参数，服务端脱敏后）、`ip`（代理头优先）、`result`（成功/拒绝/失败）和 `traceId`。响应同时回写 `X-Request-ID`，便于前端报错时按链路检索。

审计台账自身读取不会产生递归记录；凭据字段无条件打码，PII 按策略打码。

## AI 安全网关

`POST /ai/chat` 在生成回复前先跑输入网关，命中注入策略直接返回阻断提示并记录审计；通过后用脱敏后的提示词生成回复，再经过输出审核。响应在原有 `{ content }` 基础上增加 `blocked` / `risk` / `categories` 可选字段，老调用方无需改动。

策略页保存后立即生效，接真实模型时只需替换 `chat.post.ts` 中的 `buildReply(...)` 调用。

## 权限

`custom` 演示账号在安全中心只开放总览与审计的只读权限，策略页的配置按钮由 `v-permission` 隐藏。新增安全页面必须同时登记菜单（可 `hidden`）和账号白名单，否则路由守卫会按越权处理。
