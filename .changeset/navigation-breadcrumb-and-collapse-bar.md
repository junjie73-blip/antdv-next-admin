fix: 导航与面包屑这一轮 —— 把"菜单里画的"和"顶栏里显示的"接回同一份数据

用户这三句话是同一件事的三个切面："面包屑的图标和菜单栏的图标对应不上"、
"菜单的样式有点问题"、"第一次进入页面，面包屑不会自动加载上去"。
根子都在**渲染侧各自去不同的地方取数**：面包屑读路由 `meta`，菜单读后端菜单树，
图标名又散在两边写死。这一轮把真相收敛成一份，并给每处补了能钉住契约的测试。

- **面包屑的数据源换成"菜单链优先"**：原先只从 `route.matched` 取 `meta.title`，
  而文件约定路由只有**叶子**声明了 meta，父级布局记录没有标题 —— 链被砍成一格，
  再撞上"仅一级时隐藏"这条默认偏好，整条面包屑就不渲染了。表现正是"第一次进页面没加载出来"：
  登录后落地的那一屏、以及任何页面刷新后的第一帧都是空的，要到别处再回来才有。
  现在先按 `name`（再按 `path`，容忍约定路由的尾斜杠）在菜单树里反查祖先链，
  查不到才退回 `matched`，菜单里画了几级就显示几级，隐藏页也能反查到归属。
- **图标逐节点取，删掉两处兜底**：`LayoutBreadcrumb` 曾给第 0 级画"房子"、其余无图标时画"文件夹"，
  等于渲染侧替数据编故事 —— 导航根节点是 `carbon:dashboard`，面包屑却是房子，看到的"对不上"就是这么来的。
  现在每一级只用自己的 `icon`，没有就不占位。配套把页面标题与菜单标题对账
  （`分析面板` / `实时监控大屏`），两边名字不同源时"对不上"会以另一种形式复现。
- **面包屑每一级的链接指向自己那一页**：antd 的 `items[].path` 语义是
  "把前面每一级的 path 拼到当前这一级"（库注释原话 `It will concat all prev path to the current one`），
  而我们的菜单 path 本来就是完整路径，于是"系统管理 / 用户管理"被渲染成
  `#/system` 与 `#/system/system/user` —— 中键、右键新开、状态栏预览指向一个不存在的地址。
  改成传 `href`（`router.resolve` 生成，hash / history 模式都不用改），外链原样交给浏览器，
  顺带把 `isExternalPath` 抽成 `@antdv/shared/menu` 的单一判定入口（归一化与拼接都改问它）。
- **侧边菜单的层级缩进与图标对齐**：antd 的 inline 缩进是**内联** `padding-left`，
  类选择器压不过内联样式，原先那条 `[&_.ant-menu-sub_.ant-menu-item]:pl-12` 从写下起就没生效过（已删）；
  层级现在统一由 `inlineIndent = 16` 决定。图标占位另有一处死代码：针对 `.anticon` 的规则
  对本项目 `<Icon>`（`@iconify/vue` 渲染 span，不带 anticon 类）永不命中，改成 `.ant-menu-item-icon`。
  `buildMenuItems` 新增 `keepIconSlot`：侧栏里没图标的项也补一个空槽，
  宽度由 antd 的 icon token 托管（与真图标严格等宽），整列文字左边缘因此在同一条竖线上；
  顶栏横向导航不开这个开关 —— 那里白留一格会挤掉一个菜单项，溢出时更明显。
- **折叠入口挪到侧栏底部**：放在顶栏时要点到屏幕右上角才能收起"左边这一列"，动作和目标隔着整个屏幕。
  现在是贴着这一列底边的一条横杠（带 `aria-expanded` / `aria-label`），
  浮层形态（窄屏抽屉）不渲染，抽屉没有"折叠"可言、开合由抽屉负责；
  侧栏常驻的形态顶栏就此不再重复给按钮（两个按钮管同一个状态必然漂移）。
- **图标名对账**：`<Icon icon="carbon:xxx" />` 写错名字**不报任何错** —— 构建期查不到就渲染成空 span，
  运行时取图则变成一次常被 CORS 挡掉的网络请求，于是"有的项有图标、有的整格空白"。
  本轮巡检前仓库里有 45 个不存在的图标名。新增 `test/icon-names.test.ts` 静态扫描
  源码与 mock 菜单种子数据里的每个 `collection:name` 字面量，逐个核对是否真在已装的图标集里。

测试口径（这一轮的验收都指向"两边同源"而不是"看起来还行"）：

- `packages/shared/__tests__/menu.test.ts` 45 条：新增 `keepIconSlot` 正反两向契约
  （空槽必须是裸 span、有图标的不能被覆盖），以及 `isExternalPath` 的内外链判定。
- `packages/layouts/__tests__/breadcrumb.test.ts` 12 条：菜单链优先、"只有叶子声明 meta.title 时不许砍掉父级"、
  菜单未加载时才退回 `meta.title`、按 path 反查（容忍尾斜杠）、隐藏页反查、无名字节点不占一格。
- `apps/web/test/menu-icon-slot.test.ts`：把 antd `Menu` 真挂起来数 DOM ——
  "空 span 会被打上 `.ant-menu-item-icon` 并取得等宽"这条前提属于 antd 的实现，
  只看"我传了个渲染函数"的单测盖不住。
- `apps/web/e2e/layout.spec.ts` 32 条（原 25 条）：登录落地首屏与刷新后首帧的完整链、
  面包屑 href 与"点父级不掉进拼错的地址"、按标题把面包屑图标与菜单图标逐项比对（比 `svg` 字形而不是图标名），
  同层菜单文字左边缘对齐、底部折叠条的收起/展开与宽度回弹、常驻形态顶栏无重复入口而窄屏抽屉仍然有。
- 其中两处断言按**等稳**而不是"加延时"写：折叠后的宽度在 CSS 过渡里会连续变，
  `settledWidth()` 要连续两次采样相等才读值；同层文字对齐必须先把不可见副本（`width === 0`）滤掉 ——
  这两条单独跑常常躲得过、全量并发跑就红，属于时序假绿，判定条件因此写成"停住了才读"。
